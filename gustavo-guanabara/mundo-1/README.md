## Como ler os arquivos

Cada desafio começa com um **cabeçalho** que traz o enunciado e os conceitos usados. Abaixo dele está a **sua solução**. Os comentários marcam o que foi ajustado:

| Marca | Significa |
|---|---|
| `# CORREÇÃO:` | tinha um erro, e o código foi corrigido |
| `# MELHORIA:` | funcionava, mas o código mudou para ficar mais robusto ou mais limpo |
| `# DICA:` | só um comentário, e o código ficou como estava |
| `# Outra forma` | um jeito alternativo, adicionado abaixo do seu (o seu foi mantido) |

Os blocos "Jeito simplificado", "Forma otimizada" e "Jeito do Guanabara" são seus e foram mantidos.

Cada seção tem um README com as **anotações organizadas** e uma tabela de **correções e dicas** no final.

## Como rodar

Da pasta raiz do repositório:

```bash
python3 gustavo-guanabara/mundo-1/02-tratando-dados-e-fazendo-contas/desafio003_soma_de_dois_numeros.py
```

No Windows, use `python` em vez de `python3`. No PyCharm, basta abrir o arquivo e clicar em **Run**.

> O desafio 021 precisa do `pygame`: `pip install pygame`.
